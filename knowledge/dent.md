# Dent Defect

## Defect

A dent is a localized deformation of an automotive
component or surface.

## Potential Causes

- Fixture contact
- Handling impact
- Tool interference
- Component contact
- Excessive mechanical force

## Diagnostic Investigation

Inspect:

- Dent location
- Dent depth
- Dent geometry
- Fixture contact points
- Tooling
- Component clearance
- Previous operation

## Corrective Actions

- Inspect fixtures
- Verify component clearance
- Inspect tooling
- Review handling
- Monitor recurrence

## Root Cause

The detected dent is an observed visual defect.

The actual root cause requires physical and process
investigation.
