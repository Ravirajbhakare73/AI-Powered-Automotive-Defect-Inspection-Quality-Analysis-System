# Scratch Defect

## Defect

A scratch is a visible linear abrasion or surface mark
on an automotive component or painted surface.

## Potential Causes

- Fixture contact
- Tool contact
- Improper handling
- Component-to-component contact
- Contaminated contact surface
- Damaged protective material
- Process variation

## Diagnostic Investigation

Inspect:

- Defect location
- Scratch direction
- Scratch depth
- Fixtures
- Tools
- Contact surfaces
- Handling points
- Previous manufacturing operation

Check whether the same defect appears repeatedly
at the same location.

## Corrective Actions

- Inspect fixture surfaces
- Inspect tooling
- Check component clearance
- Review handling procedure
- Check protective materials
- Monitor recurrence

## Root Cause

The vision system identifies the observed scratch.

The actual root cause must be confirmed through
physical inspection and manufacturing-process
investigation.
